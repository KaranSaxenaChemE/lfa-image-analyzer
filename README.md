# LFA Image Analyzer

Browser-based Single and Batch LFA analysis, developed by Karan Saxena and Bhushan Toley, Toley Lab, Indian Institute of Science.

App: https://karansaxenacheme.github.io/lfa-image-analyzer/

- Single: upload one strip image to measure Test and Control signals and the T/C ratio.
- Batch: upload cropped images from a concentration-series experiment to generate a calibration curve and estimate the limit of detection.

Calculations run locally in your browser. Images, experimental notes and analysis results are not uploaded. The example strip is synthetic.
